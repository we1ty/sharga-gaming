Официальный репозиторий любительской команды по Dota 2 — **Sharga Gaming**. Проект представляет собой веб-сайт команды с интегрированной формой для сбора заявок от новых игроков и удобной системой координации ростера.

🌐 **Ссылка на проект:** [sharga-gaming.netlify.app](https://sharga-gaming.netlify.app/)

---

## 🎨 Дизайн и интерфейс

Визуальное оформление и интерфейс сайта полностью адаптированы на основе стилистики игровой платформы **[Yandex.gg](https://yandex.gg/)**. Проект разработан с акцентом на аккуратный UI/UX, обеспечивающий удобную экосистему для участников. В качестве основного хостинга используется **Netlify**.

---

## 📊 Текущий статус и статистика

* 📈 **Средний MMR:** Уровень игры команды находится на отметке **~2260 MMR**.
* 👥 **Особенность состава:** Формально в системе зарегистрировано 5 участников. Однако из-за высокой гибкости составов и различных комбинаций игроков в активный ростер на данный момент требуется добор. Актуальный статус на сайте указывает на `3 / 5` постоянных участников и `2` свободных слота.
* 🏆 **Цель команды:** Регулярное участие в еженедельных любительских турнирах, совместное повышение игрового уровня и развитие навыков командного взаимодействия.

### Доступные позиции для вступления:
* 🟢 **Керри** (*Safe Lane*)
* 🔵 **Мид** (*Mid Lane*)
* 🔴 **Оффлейн** (*Off Lane*)
* 🟡 **Софт саппорт** (*Soft Support*)
* 🟣 **Хард саппорт** (*Hard Support*)

## 🛠️ Функционал сайта

1. **Информационная главная страница:** Включает интерактивную бегущую строку с уведомлением о текущем наборе в команду.
2. **Форма подачи заявки:** Позволяет кандидатам отправлять свои данные для вступления в состав.
   * *Собираемые данные:* Игровой никнейм, желаемая позиция, текущий уровень MMR, контакты Telegram и ссылка на профиль Dotabuff.
3. **Валидация данных:** Интегрирована автоматическая защита от спам-ботов (скрытое поле проверки honeypot) на этапе отправки формы.
